A short poem about agency — the power to choose and to act, whether a person's, an AI agent's, or the agency that passes between them when one acts for the other. `main.ts` writes the poem to `entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
